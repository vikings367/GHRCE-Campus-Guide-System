# GHRCE Smart Campus Guide (Vercel-ready)

Static HTML deployment. No build command or framework install is required.

## Deploy
1. Upload this folder to a GitHub repository (keep `index.html` and `vercel.json` at repository root).
2. In Vercel, select **Add New → Project** and import the repository.
3. Framework preset: **Other**. Build command: leave empty. Output directory: `.` (root).
4. Deploy.

The floor maps and application logic are embedded in `index.html`.
